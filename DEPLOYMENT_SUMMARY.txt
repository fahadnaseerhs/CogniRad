📋 DEPLOYMENT STEPS (RENDER):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. PUSH TO GITHUB:
   git add .
   git commit -m "Ready for deployment"
   git push origin main

2. DEPLOY ON RENDER:
   → Go to https://render.com
   → Sign up (free)
   → Click "New +" → "Web Service"
   → Connect your GitHub repo
   → Render auto-detects render.yaml
   → Click "Create Web Service"
   → Wait 3-5 minutes

3. GET YOUR URL:
   https://cognirad-XXXX.onrender.com

4. GENERATE QR CODE:
   pip install qrcode[pil]
   python generate_qr.py https://cognirad-XXXX.onrender.com

5. ADD TO PRESENTATION:
   → Insert cognirad_qr.png into your slide
   → Students scan to join
